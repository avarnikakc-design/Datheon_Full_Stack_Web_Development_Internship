## 📌 Project Overview

This repository contains the complete codebase for all four assigned task modules under the **Datheon Full Stack Web Development Internship**. Each project is built as an independent, responsive web application and unified through a master developer portfolio.

🛠️ Task Modules & Feature Highlights
🔹 Task 1: Master Developer Portfolio (task-1-portfolio)
       Features: Modern dark/light responsive layout, technical skills highlight, dynamic project gallery, and integrated relative routing (../) to launch all task sub-apps seamlessly.

       Tech: Semantic HTML5, CSS Grid/Flexbox, FontAwesome, JavaScript DOM manipulation.

🔹 Task 2: Dynamic Task Manager (task-2-task-manager)
       Features: Everyday productivity dashboard tracking task titles, start dates, due dates, and real-time status flows (Pending, Ongoing, Completed). Features browser localStorage persistence and dynamic filter counters.

       Tech: JavaScript ES6+, DOM Events, localStorage API, CSS Custom Properties.

🔹 Task 3: SkyPulse Weather Telemetry App (task-3-weather-app)
       Features: Real-time global weather search dashboard integrating asynchronous REST API calls, temperature data formatting, and dynamic error state handling for invalid queries.

       Tech: Async/Await, Fetch API, OpenWeatherMap API, CSS Flexbox.

🔹 Task 4: LuxeCart E-Commerce Store (task-4-ecommerce)
       Features: Product storefront dynamically fetching inventory from FakeStoreAPI, instant category filtering, real-time client-side search, interactive cart state math, and slide-out cart drawer.

       Tech: REST APIs (FakeStoreAPI), JavaScript Array Methods, CSS Transitions, Dynamic DOM Rendering.
